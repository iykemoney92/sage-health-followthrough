# Agent Tool Routes

These routes are the bridge between the ElevenLabs WhatsApp agent and Sage's product state.

Target MVP tools:

- `get-user-context`
- `create-followthrough-plan`
- `update-plan-from-checkin`
- `schedule-checkin`
- `generate-progress-summary`

Start each route against demo repositories, then swap persistence to Supabase.
