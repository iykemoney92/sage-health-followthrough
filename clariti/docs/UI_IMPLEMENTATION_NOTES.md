# UI Implementation Notes

The `ui:ux/` images are the design reference for Clariti.

## Do Now

- Preserve the core empty-state composer pattern.
- Preserve the active-session three-panel layout: conversations/actions, chat, adaptive canvas.
- Treat the adaptive canvas as task-specific UI, not a generic markdown panel.
- Keep document workflows typed before building visual states.

## Do Later

- Replace scaffold panels with exact components from the product designs.
- Add upload states, extraction states, and artifact loading states.
- Add responsive versions after desktop flow is working.
- Add accessibility pass once real components replace placeholders.

## Avoid

- Do not add a marketing landing page unless the demo needs it.
- Do not add generic health dashboards before the document copilot loop works.
- Do not present Clariti as clinical diagnosis or final insurance/legal advice.
